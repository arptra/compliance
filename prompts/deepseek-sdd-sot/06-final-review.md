# Prompt 06 - Final SoT / SDD Review

Review the repository after the SoT/SDD foundation work.

Do not make new changes unless they are small fixes to the artifacts you just
created.

Check:

1. Is `AGENTS.md` clear and short?
2. Are skills usable by future CLI agents?
3. Are spec templates complete but not bloated?
4. Is architecture documentation grounded in actual repository evidence?
5. Are unknowns clearly marked?
6. Are inferred requirements clearly marked?
7. Are traceability templates usable?
8. Are validation scripts safe?
9. Is there any accidental production code change?
10. Is there any generated nonsense or generic filler that should be removed?

Then output:

# Final SoT/SDD Foundation Report

## What Was Created

## What Was Updated

## What Was Not Changed

## How Future Work Should Be Done

## Commands To Run

## Open Questions For Humans

## Risks

## Recommended First Real Feature Workflow

Also show the exact recommended workflow for a future feature:

1. Create `specs/REQ-.../`
2. Fill intake
3. Write requirements
4. Write acceptance criteria
5. Write design
6. Write tasks
7. Implement task by task
8. Update traceability
9. Run tests
10. Run SoT validation
