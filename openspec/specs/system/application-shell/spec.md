# Application Shell Specification

## Purpose

Определяет текущую доступную поверхность React-приложения, навигацию и границу между публичными и защищёнными экранами.

## Requirements

### Requirement: Защищённая область приложения
Приложение SHALL показывать рабочие маршруты только пользователю с действующей локальной сессией.

#### Scenario: Неавторизованный переход
- **WHEN** пользователь без действующего access token открывает защищённый маршрут
- **THEN** приложение переводит его на экран входа

#### Scenario: Восстановление сессии
- **WHEN** в localStorage есть token и `/api/auth/me` подтверждает его
- **THEN** приложение восстанавливает пользователя и показывает запрошенный защищённый экран

### Requirement: Текущие рабочие маршруты
Приложение SHALL предоставлять маршруты `/gigachat`, `/gigachat/lake`, `/gigachat/background` и `/profile` внутри общего layout.

#### Scenario: Открытие корня
- **WHEN** авторизованный пользователь открывает `/`
- **THEN** приложение перенаправляет его на `/gigachat`

#### Scenario: Неизвестный маршрут
- **WHEN** авторизованный пользователь открывает неизвестный путь
- **THEN** приложение перенаправляет его на `/gigachat`

### Requirement: Навигация GigaChat Lab
Layout SHALL показывать ссылки на GigaChat Lab, загруженные данные, фоновые задачи и профиль, а также действие выхода.

#### Scenario: Сворачивание меню
- **WHEN** пользователь сворачивает или разворачивает боковое меню
- **THEN** выбор сохраняется в localStorage и восстанавливается после перезагрузки

### Requirement: Единый HTTP-клиент
Frontend SHALL отправлять Bearer token из localStorage во всех поддерживающих авторизацию API-запросах и SHALL преобразовывать неуспешный HTTP-ответ в ошибку интерфейса.

#### Scenario: Авторизованный запрос
- **WHEN** access token сохранён
- **THEN** HTTP helper добавляет `Authorization: Bearer <token>`

#### Scenario: Ошибка API
- **WHEN** API возвращает не-2xx статус
- **THEN** HTTP helper отклоняет операцию с текстом ответа сервера
